# CodeAlpha_Calculator
**Task 2** of the CodeAlpha Frontend Development Internship: a calculator built with HTML, CSS and JavaScript.

**Live demo:** https://pakeezaa58-tech.github.io/CodeAlpha_Calculator/

## Features

- Addition, subtraction, multiplication and division
- Clear (C), backspace, percent and plus/minus keys
- Chained calculations (for example 2 + 3 + 4 =)
- Live display with the current expression above the result
- Division by zero shows an error message
- Keyboard support: digits, + - * /, Enter, Backspace and Esc
- Responsive layout and animated key presses

## Technologies

HTML5, CSS3 (Grid, transitions), JavaScript (ES6). No libraries and no use of `eval()`.

## Project structure

```
CodeAlpha_Calculator/
├── index.html
├── style.css
└── script.js
```

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser.
